# Agent SDK

Future SDK for building the planner/agent loop described in
docs/architecture/03-AI-ARCHITECTURE.md (Observe → Plan → Policy Check →
Act → Observe → Verify → Recover) against a chosen `AIProvider`.

No planner exists in Phase 1 — this package is a placeholder. See
docs/roadmap/PHASE-1-SCOPE.md for what Phase 1 actually implements
(the contracts and state machine the future agent loop will run inside).
