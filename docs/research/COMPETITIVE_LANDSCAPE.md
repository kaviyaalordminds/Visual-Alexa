# Competitive Landscape (Summary)

This file is the entry point requested by the Phase 1 brief §3. The detailed,
maintained content lives in the numbered research documents in this folder;
this file indexes them and states the top-line conclusion so a reader does
not have to open every file to get the gist.

- Full landscape survey (10+ systems, per-system capability notes, sourcing
  confidence): `01-LANDSCAPE.md`
- Full capability comparison matrix: `02-COMPETITIVE-MATRIX.md`

## Top-line conclusion

No surveyed product combines all of: local-first execution, structured
(non-coordinate) UI grounding as the default, capability-scoped agent
permissions, an explicit observe/verify/recover task lifecycle, ambiguity
resolution, persistent structured memory, and an original visual identity.
Products cluster into voice-first cloud assistants (Alexa, Siri, Assistant),
screen-aware advisory copilots (Copilot Vision), and screenshot-driven
computer-use capabilities (Claude computer use, OpenAI's computer-use agent)
— each strong in one dimension and thin or absent in the others. VEYRA's
opportunity is architectural integration across these dimensions on a single
user-owned Windows PC, not a novel capability no one has thought of.

See `02-COMPETITIVE-MATRIX.md` for the full row-by-row comparison and
`03-COMPETITOR-WEAKNESSES.md` for the evidence behind each gap.
